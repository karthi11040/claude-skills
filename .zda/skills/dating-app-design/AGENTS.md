# Agent Instructions: Dating App Design System

## Trigger Condition
Activate when the user asks to design, evaluate, or code a mobile dating app, swipe interface, matching flow, or profile system.

## Design Rules
1. **Canvas & Card Dimensions**:
   - Device: iPhone 16 (`393 × 852 px`).
   - Card width: `353 px`, corner radius: `24–28 px`.
   - Bottom Dock height: `84 px`, home indicator `138 × 5 px`.
2. **Color Palette**:
   - Background: `#0D0E16`
   - Primary Accent: Linear Gradient `["#FF385C", "#FF6584"]`
   - VIP/Spotlight: Linear Gradient `["#8B5CF6", "#D946EF"]`
   - Border lines: `#FFFFFF15`
3. **Hierarchy**:
   - Always include a dark gradient scrim (`#00000000` to `#080911F5`) over the bottom portion of photo cards to guarantee AAA readability for text.
   - Action buttons must be ergonomically ordered: Rewind (left), Pass, Super Like, Radiant Like (largest, center-right), Boost (right).
